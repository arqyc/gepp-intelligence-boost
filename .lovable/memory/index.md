# GEPP Intelligence Website

## Design System
- Fonts: Space Grotesk (headings), Inter (body)
- Primary green: hsl(152, 68%, 36%) — Deep sustainable green
- Background: hsl(140, 20%, 97%) — Warm off-white with green undertone
- Foreground: hsl(150, 20%, 8%) — Deep forest charcoal
- Eco Amber: hsl(38, 92%, 55%) — Warm amber accent
- Signal Blue: hsl(211, 100%, 50%) — #007AFF for interactive elements
- Eco-friendly aesthetic: Leaf/Recycle icons, circular motifs, organic gradients
- No animated number counters. Static bold figures.

## Structure
- 6 pages: Home, Platform, Scope 3, Traceability, About, Contact
- EN/TH language toggle via LanguageContext
- Login redirects to geppdatasolutions.com
- Founders: Mayuree (Mam) CEO, Dome CMO

## Anti-patterns to avoid
- No hamburger menus on desktop
- No generic "Solutions" page
- No stock photos of people in suits
